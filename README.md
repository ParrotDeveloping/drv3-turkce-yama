## Klasörler

- `tr/` — yamaya giren çeviriler (`<id>\t<metin>` TSV)
- `translation/` — İngilizce + Türkçe referans JSON
- `batches/` — çeviri parti dosyaları
- `tools/` — CPK/SPC/STX okuma-yazma ve yama araçları (Python)
